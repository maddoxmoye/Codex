# Wildfall — The Emberwood · Windows playtest 0.2.1

For 64-bit Intel/AMD Windows 10 or 11 laptops and PCs. This is a portable game: no installer or administrator access is required by the game itself.

1. Download Wildfall-Emberwood-Windows-x64.zip.
2. Right-click the ZIP → Extract All. Keep every extracted file together.
3. Open the extracted folder and double-click Wildfall-Emberwood.exe.
4. Choose an archer, then Start Run.

The .pck contains the game; do not move the .exe away from it.

If frame rate is low, open Settings and select Performance. F11 switches between fullscreen and windowed mode. The renderer requires a Vulkan-capable GPU and current graphics drivers. Actual performance depends on your laptop; the automated Windows startup check is not a GPU benchmark.

This playtest is unsigned. Windows may display SmartScreen. For your own downloaded copy from the official maddoxmoye/Codex release, More info → Run anyway is available on unmanaged machines. If your workplace blocks the app, use an approved personal computer or ask IT; this package does not bypass work-device policies.

## Controls

- WASD: move
- Space: selected archer's defensive/mobility ability
- E: offensive ability
- Right-drag: orbit camera
- Mouse wheel: zoom
- Esc: pause, stats, settings and restart
- F11: fullscreen/windowed

Five unlocked archers, twenty waves, four guardians, purchased pets and elemental quivers. The new illustrated selection cards and hopping chest rewards are included. All game rules match Mac 0.2.1. Settings persist locally; unfinished runs do not yet save between sessions.
